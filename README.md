# Pixel Pomodoro

Пиксельный помодоро-таймер на чистом tkinter. Фиолетово-розовая тема, маскот-помидорка,
8-битный звук, уведомления рабочего стола.

## Установка зависимостей на Arch

```bash
sudo pacman -S python tk            # зависимости
sudo pacman -S libnotify            # по желанию: уведомления
```
## Установка репотизитория и сборка под Arch

```bash
# Клонируем репозиторий
git clone https://github.com/sendox2012-debug/PixelPomodoro.git

# Переходим в директорию проекта
cd PixelPomodoro

# Запускаем скрипт установки (устанавливает в ~/.local, без root)
./install.sh
```

После этого ищи **Pixel Pomodoro** в меню приложений или запусти `pixel-pomodoro`

# Программа работает не только в Arch а на всех дистрибуивах сделаных поверх арч линукса по типу: Cachyos, GarudaOs
